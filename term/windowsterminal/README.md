# terminal preference for `WindowsTerminal`

## build.deno.ts

make `WindowsTerminal` settings.json file from `src`

### Usage:

```bash
deno ./build.deno.ts
```

## Update-WindowsTerminalLocation.ps1

update `$env:WINTERM_PATH` user env variable from `WindowsTerminal` executable location for `WindowsTerminal` icon preference

### Usage:

```powershell
./Update-WindowsTerminalLocation.ps1
```
